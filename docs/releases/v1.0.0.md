# GEM-PIC-RZ 1.0.0

First release, the version described in A. Pukhov, *GEM-PIC-RZ: a Galilean electromagnetic particle-in-cell code
in quasi-cylindrical geometry with nonuniform grids*, arXiv:2610.31622 (2026).

**Physics and numerics**
- Galilean electromagnetic PIC (GEM-PIC) in azimuthal modes: forward field with its slow derivative, no Courant
  condition, steps much larger than the cells.
- Free-hand non-uniform grids along r, ζ and z; finite-volume radial operators with an exact discrete Gauss law.
- Lasers, bunches (Gaussian, flat-top, function profiles, from openPMD / native files, Fawley shot noise,
  `axis_refine` near the axis), plasma with mobile ions, ADK field ionization, transport elements (quadrupoles,
  plasma lenses, solenoids, thin chicanes), planar and helical undulators (FEL), flying focus.
- Beam push with the Vay pusher; with undulators in the mean field of the two levels of a step.

**Backends and I/O**
- Serial and OpenMP engines (same algorithm, same results) and a CUDA engine (verified in GPU emulation, not yet
  run on a GPU); MPI pipeline along ζ.
- Text, HDF5 and openPMD output (rectilinear meshes for non-uniform grids), checkpoints and restart,
  wall-time stop; browser GUI (`tools/gempic_gui.py`).

**Validation**: 30 ctest tests; benchmarks against FBPIC (wake, laser evolution, ionization injection), GENESIS 4
(seeded FEL) and the radiation integral (undulator emission), see `benchmarks/README.md`.
